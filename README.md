我的个人起始页 — 简洁、便捷、多端同步

</div>

## 关于

基于 [Bius-Start (布斯起始页)](https://github.com/yubius/Bius-Start) 改造的个人定制版本，用于浏览器新标签页。

## 特性

- 纯静态部署，托管于 GitHub Pages
- 多设备配置同步：访问 `?u=me` 自动加载云端配置
- 整合个人书签
- 9 张本地壁纸 + 必应每日 + Unsplash 随机
- 6 大搜索引擎一键切换

## 部署

1. 在 GitHub 创建仓库 `Maper0618.github.io`
2. 推送本仓库代码到 main 分支
3. 在 Settings → Pages 启用 GitHub Pages
4. 访问 `https://Maper0618.github.io/?u=me` 即可

## 配置

云端配置仓库：[my-start-config](https://github.com/Maper0618/my-start-config)

直接编辑 `me.json` 中的 `custom` 数组即可添加 / 修改导航项。
